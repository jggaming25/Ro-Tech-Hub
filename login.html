Mit Discord anmelden

Kein Passwort, keine separate Registrierung: Beim ersten Login wird automatisch ein Hub-Konto mit deinem Discord-Profil erstellt.

So funktioniert die Anmeldung

Bei der ersten Anmeldung senden wir einen 6-stelligen Code an deine Discord-E-Mail-Adresse. Danach ist dein Konto bestätigt. Optional kannst du im Konto zusätzlich E-Mail-MFA aktivieren – auch dann wird bei jeder Anmeldung ein Code verlangt.

Mit der Anmeldung akzeptierst du, dass dein Konto für Bestellungen, Bewertungen und Discord-Rollen verwendet wird. Es gelten die Regeln der Roblox-Community.
